## 现在房间里住了个小人，叫「小线」

房间还是原来那个房间，但多了一个会自己溜达、会说话、能听懂你指令的线稿小人。

他是用和房间**完全相同的画法**画的 —— 同样是黑线白面、同样会被家具挡住、同样在夜里反相。他有一套最小的真人感：走路前先转身、快到了会减速、站着的时候手臂不会僵直。

## 一、只想看看房间（不用装任何东西）

**双击 `room.html`** 就能看。

鼠标划过门、窗、百叶帘、抽屉、台灯、杯子、椅子、柜门、书、挂钟、抱枕、唱机、画、地球仪、吊扇、风铃、植物、球 —— 线条会变粗、光标变手型，点击有对应的音效和动画。**没有任何按钮和说明，全靠探索。**

晚上 19:00 之后打开，房间会变成黑底白线。这时点墙上的电灯开关，或者把台灯拉起来 —— 会亮出一片锥形的光亮区域。

> 这样打开时，**左下角的对话框会出现但连不上后端**，因为没有服务器。想看小人的话走第二步。

## 二、把小人和对话跑起来（三步）

### 前提

你机器上已经有 Python 3.13。依赖我已经装在 `server/.venv` 里了，**只要你没删掉这个文件夹，就跳过第 1 步直接做第 2 步**。

### 1. 装依赖（仅当 `.venv` 不存在时）

打开终端（PowerShell 或 cmd 都行），逐行运行：

```bat
cd E:\pure-line-room-main\server
python -m venv .venv
.venv\Scripts\python.exe -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

> 注意必须带 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 这个参数。直连官方源在这台机器上会超时。

### 2. 启动服务

```bat
cd E:\pure-line-room-main\server
.venv\Scripts\python.exe -m uvicorn main:app --port 8000
```

看到 `房间已就绪` 就是成功了。**这个终端窗口要一直开着**，关掉服务就停了。

（如果你在 Git Bash 里，把 `.venv\Scripts\python.exe` 换成 `./.venv/Scripts/python.exe`）

### 3. 打开浏览器

访问 **http://127.0.0.1:8000**

左下角会出现一个白底黑框的对话框，和房间是同一套线描语言。里面有小人「小线」，站在房间中间。

## 三、怎么玩

### 跟小线说话

在对话框里打字，回车发送。

| 你说 | 他会做什么 |
|---|---|
| `帮我打开电扇` | 走到吊扇下面，拉绳子打开，然后回你一句 |
| `把窗帘拉下来` | 走到窗边，把百叶帘放下来 |
| `放首歌听听` | 走到唱机旁边，放黑胶，然后开始有循环的音乐 |
| `把灯关掉` | 走到墙上的开关，按掉 |
| `踢一下球` | 跑过去把球踢起来，弹三下 |
| `你在干嘛呀` | 纯聊天，随口答你 |
| `今天好累啊` | 纯聊天，不会去动任何东西 |

几个要知道的点：

- **命令类要等几秒**。因为他是真的**走过去再动手**，不是瞬间遥控。这是故意的 —— 走过去这个动作本身就是「生活小人」的意思。嫌慢的话调 `room.html` 里的 `MAN_SPEED`。
- **他的回复很短**，6~22 个字，还带「诶」「哇」「嗯——」这种语气词。人设是好奇心旺盛、话多、有点小朋友脾气。
- **打字的时候他会转过来面向你**，头顶冒一个小气泡显示他在说什么。
- 直接**点小人也能聚焦到输入框**。

### 不管他的时候

小线会**自己活动**：走去百叶帘看看、把书抽出来、打开吊扇、自己放一张黑胶、或者嘟囔一句「好安静啊」。

规则是：

- 你说话之后的 10 秒内他会安静下来听你说
- 之后大约每 7 秒做一次决定
- 页面关掉时他就不动了（不会浪费）

### 房间本身的交互

和小人无关，这些一直在：

- **悬停**任意家具 → 线条变粗
- **点击** → 开合 / 播放 / 弹跳，各有专属音效
- **日夜自动切换**：19:00–7:00 进夜晚，背景变黑、线条变白
- **台灯锥形光**：夜晚不开大灯时，拉起台灯会亮出一块锥形的白天区域（用 24 个裁剪面 + 两遍渲染做的）

## 四、让他真的会聊天（可选，但强烈建议）

**现在的小线用的是「规则大脑」**：能听懂上面那张表里的指令，聊天回复也是固定话术池里挑的（`诶？你说什么呀。` / `嗯——我在听。` 这种）。

想让他真的会说话，配一个 LLM。任何 **OpenAI 兼容接口**都行 —— DeepSeek、通义千问、硅基流动、本地 Ollama / vLLM 都可以。

```bat
cd E:\pure-line-room-main\server
copy .env.example .env
```

然后**用记事本打开 `server\.env`**，填三行：

```ini
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_API_KEY=sk-你的密钥
```

（去 DeepSeek 开放平台注册就能拿到 key。换别家就改 base_url 和 model，`.env.example` 里还有通义和本地 Ollama 的例子。）

存盘后**重启服务**（Ctrl+C 停掉再运行一次第 2 步）。启动日志里会打印用的是哪个模型还是规则大脑。

## 五、目录结构

```
pure-line-room-main/
├── room.html          ← 房间 + 小人 + 对话框，全部前端逻辑
├── audio.js           ← 音效，全部用 Web Audio 现场合成，不依赖素材
├── sounds/            ← 几个真实录音（关门、开窗、柜门），可选，删了也能跑
├── README.md
└── server/            ← 小人的大脑
    ├── main.py        ← HTTP 服务：托管页面 + 三个接口 + 自主活动的后台循环
    ├── agent.py       ← LangGraph 行为图
    ├── brain.py       ← 双大脑：LLM / 规则，自动降级
    ├── devices.py     ← 19 个可操控设备的白名单 + 中文别名
    ├── requirements.txt
    ├── .env.example
    └── .venv/         ← 依赖（几百 MB，删了要重装）
```

### 它是怎么运作的

```
浏览器                          服务端
  │                               │
  ├─ 每 380ms GET /events ───────►│  取回小人的自主活动事件
  │                               │  （去哪、动什么、说什么）
  │                               │
  ├─ 每 1.2s POST /state ────────►│  汇报房间设备状态 + 小人位置
  │                               │
  └─ 打字 POST /chat ────────────►│  跑 LangGraph → 回复 + 动作
                                  │
                     LangGraph 行为图：
                       (用户说话) → 识别意图 → LLM 出回复和动作 ─┐
                       (没人说话) → 加权选择 → 偶尔叫 LLM 嘟囔 ─┴→ 白名单校验
```

两个关键设计：

1. **LLM 只出意图，不出运动**。走走停停是浏览器里 60fps 跑的（网格 A\* 绕开家具 + 转向平滑），服务端只发「去窗边」这种几秒一条的意图。让 LLM 驱动每一帧会又慢又贵又乱抖。
2. **规则和 LLM 是并联的**。即使 LLM 挂了或者 key 填错，「帮我打开电扇」这种直球指令**依然会被执行**（只是回复变成一句兜底的），因为意图识别有一层不依赖 LLM 的规则。

### 两个可以调的参数

在 `server\.env` 里：

```ini
IDLE_TICK_SEC=7    # 自主活动多久做一次决定
IDLE_GAP_SEC=10    # 你说话之后他安静多少秒
```

## 六、出问题了

| 现象 | 原因和解决 |
|---|---|
| 对话框写「他没听见——要先启动 server」 | 服务没启动，回去做第二步 |
| 一开始就写「连不上服务器了」 | 服务挂了，或者端口被别的程序占了。换端口：`--port 8001`，然后浏览器也访问 `127.0.0.1:8001` |
| 回复永远是那几句固定的话 | 没配 `.env`，正在用规则大脑。见第四节 |
| 配了 `.env` 但还是规则大脑 | 启动日志里会说明原因（key 错 / 模型名错 / 连不上）。改完要**重启服务** |
| 命令说了但他不动 | 看一眼对话框有没有回复。有回复没动作 = LLM 给了动作但设备名不对，看下面一行的日志 |
| 小人卡在家具里 / 穿模 | 告诉我，是导航的家具包围盒要调 |
| 房间本身卡顿 | 关掉服务器试试。如果关了还是卡，是原来房间的问题，和这次改动无关 |

**把服务停掉**：在那个终端里按 `Ctrl + C`。
